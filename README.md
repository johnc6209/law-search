# 법령·죄명 검색

「공소장 및 불기소장에 기재할 죄명에 관한 예규」(공소청예규 제81호, 2026. 10. 2. 시행)를 기준으로 법령 조문의 죄명을 찾고, 자주 쓰는 법령 링크(casenote.kr)로 바로 가는 정적 웹페이지입니다.

- `index.html` 하나로 동작합니다. 외부 라이브러리는 없고, 압축 전송 기준 약 20KB입니다.
- 죄명 검색 예: `형법 250조`, `특가법 5조의3 1항 2호`, `성폭법 14조 2항`, `식품위생법 94조`, `위험운전`
- 결과에 있는 죄명을 누르면 클립보드에 복사됩니다.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 배포용 페이지(빌드 결과물) |
| `data/죄명표.txt` | 예규 별표 1~5 죄명 데이터 |
| `tools/template.html` | 페이지 원본(데이터 자리 `/*DATA*/`) |
| `tools/build.py` | 데이터를 원본에 넣어 `index.html` 생성 |
| `tools/parse_pdf.py` | 예규 PDF 텍스트(`pdftotext -layout`)에서 형법·군형법 죄명표 추출 |

## 예규가 개정되면

1. `data/죄명표.txt`를 고칩니다.
2. `python3 tools/build.py`를 실행합니다.
3. 커밋하고 push합니다.

### 데이터 형식

```
@죄명표상 법령명|casenote 주소용 법령명|별표 번호
조|항|호|죄명|조건(선택)|!(개별 죄명 펼치기 안 함, 선택)
#안내 문구
```

- 죄명 맨 앞의 `~`는 `법령명위반`으로 바뀝니다.
- 조 자리의 `*`는 그 외 조문, 또는 조문과 상관없이 적용되는 항목입니다.
